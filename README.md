# 🌦 Power BI Weather Dashboard

This project is a **Power BI dashboard** that visualizes real-time and forecast weather data using a public weather API.  
It includes temperature, humidity, wind speed, air quality, sunrise/sunset times, and rain chances for multiple cities.

## 📸 Dashboard Preview
![Dashboard Screenshot](screenshots/dashboard.png)

## 🛠 Features
- Real-time current weather data
- 7-day forecast with temperature trends
- Air Quality Index with PM10, PM2.5, CO, SO2, NO2, O3
- Sunrise & sunset times
- Rain probability visualization
- City switching (Lucknow, Mumbai, Surat)

## 🗂 Data Source
- [WeatherAPI](https://www.weatherapi.com/) (Free API tier)
- Power Query used to transform JSON → Power BI data model

## 🔧 How to Use
1. Clone this repository or download `weather_dashboard.pbix`.
2. Open in Power BI Desktop.
3. Replace `YOUR_API_KEY_HERE` with your own Weather API key in Power Query.
4. Refresh the dataset.
